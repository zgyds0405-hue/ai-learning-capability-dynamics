# 六联三维演化图：审阅预览

本轮仅计算并绘制预览，未修改 LaTeX 文档、已有论文 PDF、原图件或 `LATEX文档.zip`。

图中横向为有效学习时间 T，纵深为目标权重 w，竖轴为综合能力 h3=w·h1+(1−w)·h2。每幅图均显示 w=0、0.25、0.5、0.75、1 五条曲线；w 是独立能力的评价权重，w=0 只评价协作能力，w=1 只评价独立能力。它不是 AI 使用时间比例，也不进入能力演化方程。

| 面板 | 改变因素 | β | ε | 对照含义 |
|---|---|---:|---:|---|
| a | 内化效率 | 0 | 0.10 | 关闭 AI 知识内化 |
| b | 内化效率 | 0.48 | 0.10 | 论文基准 |
| c | 内化效率 | 0.80 | 0.10 | 较强内化，沿用既有联合扫描的上端 |
| d | 基础协作支持 | 0.48 | 0 | 协作形成条件仅由独立知识支持 |
| e | 基础协作支持 | 0.48 | 0.10 | 与 b 相同的基准，便于两行比较 |
| f | 基础协作支持 | 0.48 | 1 | g(h1)=1，协作形成条件不再依赖 h1 |

所有面板固定 AI 时间比例 u=0.50，T∈[0,20]，h1(0)=0.20、h2(0)=0.10，a=0.25、c=0.55、δ1=0.02、δ2=0.03；每个面板只改变表中的 β 或 ε，未优化 u。速率单位为模型时间的倒数，ε、w、能力指数无量纲。β 是内化形成率，不是第三种能力存量。

六面板包含五组不同的动力学条件，因为 b/e 故意重复同一基准。每组条件只积分 h1、h2，再计算五种权重的 h3；因此是六个显示面板、三十条评价曲线，而不是三十种不同的能力形成机制。

配色与半透明切片参考用户提供的图片。实线使用全部 2001 个保存时点，圆点仅标记每1个模型时间单位；半透明区域从曲线填充到零，作为分层视觉辅助，不表示置信区间、额外观测或新的能力变量。未照搬参考图中的突跃形状。

三维投影会让相同高度在不同权重切片中显示于不同屏幕位置，曲线在屏幕上向下倾斜也不等于 h3 随时间下降。应按竖轴读值；建议打开交互 HTML，悬停读取 T、w、h1、h2、h3，并旋转查看。权重改变只是重新评价同一能力状态，不应解释为提高 w 会导致能力增长。

## 文件

- `figures/h3_weights_beta_epsilon_3d.png`：300 dpi 六联图预览。
- `figures/h3_weights_beta_epsilon_3d.pdf`、`.svg`：可编辑矢量版本；`.tiff` 为600 dpi栅格版本。
- `h3_3d_interactive.html`：离线交互版，无需网络；旋转一幅图时同步相机，点击权重图例可隐藏/显示相应切片，悬停读取真实数值。
- `panels/`：六张分图，便于单独放大检查。
- `data/trajectories.npz` 与 `all_trajectories.csv`：全部轨迹（60030 行）；`endpoints_T20.csv` 为终点对照。
- `qa/`：步长、独立求解器、解析特例、版式、字号、碰撞与文稿未修改记录。

当前310×220 mm为大尺寸审阅画布，待图件确认后再适配论文版心，当前未插入论文。

## 数值与图件核验

主积分 RK4 步长0.01，复核步长0.005；另用独立写出的方程和 DOP853 验证五组完整轨迹，全部低于1e−7。检查了 β=0 的独立能力解析特例、ε=1 的协作能力解析特例、w=0/1 的端点恒等式和 b/e 的完全一致性；无数值截断。基准轨迹与原保存结果一致。

版式检查以相同相机、轴范围和相等面板尺寸比较六图。碰撞检查若对三维填充边界给出 WARN，会在人工复核记录中说明；不将这些提示隐藏或当作数值误差。

## 复现

Python依赖：numpy、scipy、matplotlib、plotly。当前使用 Microsoft YaHei、Arial、DejaVu Sans；在其他系统运行需提供可显示中文的字体。

```powershell
python -B generate_preview.py
```

脚本只写本预览目录，使用原工作区模型，或独立目录中的 `reproduction/model.py`。不会执行论文编译、修改正文或重打包论文工程。
